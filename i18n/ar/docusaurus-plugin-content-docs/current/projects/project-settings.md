# Project Settings

Manage your project configuration and preferences.

## Access Settings

1. Go to your project
2. Click **Settings** in the left sidebar
3. Configure options below

## General Settings

- **Project name** — Change the project name
- **Description** — Add or update project description
- **Base language** — Your source language (cannot be changed)

## Languages

Add or remove target languages for translation.

### Add a Language
1. Click **+ Add Language**
2. Select the language
3. Click **Add**

### Remove a Language
1. Find the language in the list
2. Click **Remove**
3. Confirm deletion

## Export Settings

Configure default export formats and options.

## Visibility

- **Public** — Anyone can view
- **Private** — Only team members can access
