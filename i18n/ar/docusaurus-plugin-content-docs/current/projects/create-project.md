# Create a Project

A project is the container for all your translatable strings and translations.

## Create a New Project

1. Log in to your Wordiy dashboard
2. Click **+ New Project**
3. Enter project details:
   - **Project name** — Something descriptive
   - **Base language** — Your source language
   - **Description** — Optional notes
4. Click **Create Project**
