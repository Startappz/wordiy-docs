# Translate Strings

Translate your uploaded strings into target languages.

## Start Translating

1. Go to your project
2. Click **Translations**
3. Select a target language
4. Enter translations for each string
5. Click **Save**

## Translation Features

- **Search** — Find strings quickly
- **Filters** — Show only untranslated or in-progress strings
- **Comments** — Leave notes on translations
- **History** — View previous translations

## Tips

- Keep translations concise and natural
- Use translation memory for consistency
- Ask for reviews before finalizing
