# Review Translations

Quality-check translations before exporting.

## Review Process

1. Go to **Translations**
2. Filter by **Pending Review**
3. Check each translation
4. Approve or request changes
5. Translator makes updates
6. Approve final version

## Reviewer Checklist

- ✅ Spelling and grammar
- ✅ Tone matches original
- ✅ Technical terms are correct
- ✅ Formatting is preserved
- ✅ Context makes sense

## Approval Status

- **Pending** — Awaiting review
- **Approved** — Ready to export
- **Rejected** — Needs revision
