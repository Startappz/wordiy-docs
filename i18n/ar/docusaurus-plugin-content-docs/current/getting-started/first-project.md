# Create Your First Project

A project is where all your translatable strings and translations live.

## Step 1: Start Creating

1. Log into your Wordiy account
2. Click **New Project** in your dashboard
3. Enter a project name (e.g., "My App", "Website v2")
4. Select your base language (the language your strings are currently in)

## Step 2: Configure Settings

- **Project name** — Choose something descriptive
- **Base language** — The source language for your strings
- **Description** — (Optional) Add notes about the project

## Step 3: Add Target Languages

Choose which languages you want to translate into:
- English, Spanish, French, German, Chinese, Japanese, Arabic, etc.
- You can add more languages later

## Step 4: Set Up Your Team

- Invite team members to help with translations
- Assign roles (Translator, Reviewer, Manager)
- Set permissions

## Step 5: Upload Strings

You're ready to upload your translatable strings. See [Upload Strings](../translations/upload-strings.md) for more details.
