# Export Translations

Download your completed translations in various formats.

## Export Your Translations

1. Go to **Translations**
2. Select target language(s)
3. Choose export format
4. Click **Export**
5. Download the file

## Supported Formats

- **JSON** — For JavaScript/web apps
- **YAML** — For configuration files
- **CSV** — For spreadsheet tools
- **Properties** — For Java apps
- **XML** — For Android apps
- **XLIFF** — For CAT tools

## Export Options

- **Include all strings** — Export everything
- **Only approved** — Export only reviewed translations
- **Exclude empty** — Skip untranslated strings

## Integration

Use the REST API to automate exports and sync with your app.
