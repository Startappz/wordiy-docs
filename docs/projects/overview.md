# Organizations & Projects

Wordiy uses a hierarchical structure with **Organizations** at the top level and **Projects** within each organization. This structure allows you to manage multiple translation projects efficiently.

## Understanding the Structure

### Organizations

An **Organization** is the top-level container that:
- Groups all your translation projects
- Manages team members and their roles
- Handles billing and subscription plans
- Controls shared settings and configurations

### Projects

A **Project** is a translation unit within an organization that:
- Contains all translatable strings for your application
- Manages multiple languages and translations
- Tracks translation progress and status
- Handles import/export of translations

## Organization Hierarchy

```
Organization
├── Members (with roles)
├── Billing & Subscription
├── Settings & Integrations
└── Projects
    ├── Project 1
    │   ├── Languages
    │   ├── Strings & Translations
    │   └── Export Formats
    ├── Project 2
    └── Project 3
```

## Key Concepts

### Organization Roles

Each organization member can have different roles:

- **Owner** — Full access to organization, projects, billing, and team management
- **Manager** — Manage projects, team members, and settings
- **Translator** — Translate strings and review translations
- **Reviewer** — Review and approve translations
- **Viewer** — View-only access to projects and translations

### Project Status

Projects can have different statuses:

- **Active** — Project is in use
- **Archived** — Project is no longer active but data is preserved
- **Draft** — Project is being set up

## Getting Started

1. **Create or join an Organization** — Set up your translation workspace
2. **Create a Project** — Start your first translation project
3. **Add team members** — Invite translators and reviewers
4. **Upload strings** — Add your application's translatable content
5. **Manage translations** — Collaborate with your team on translations
6. **Export** — Download translated files for your application
