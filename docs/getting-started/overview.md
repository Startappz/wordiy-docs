# Welcome to Wordiy

Wordiy is a professional translation management platform that helps teams collaborate on translating web and mobile applications.

## What is Wordiy?

Wordiy simplifies the process of managing translations across your projects. Whether you're building a single-language app or supporting multiple languages, Wordiy provides the tools you need to:

- **Upload and organize** your translatable strings
- **Collaborate** with professional translators and reviewers
- **Automate** translations with machine translation providers
- **Export** translated content to your applications
- **Manage teams** with role-based permissions
